У файлі ci.yml згенерувати робочий процес (workflow) з наступними вимогами: 
○ Trigger: Запускати акцію при push або pull request у гілку, що містить в назві develop чи master . 
○ Job: Створити одну Job (наприклад, cross_build). 
○ Strategy: 
	Використати матрицю (strategy: matrix) для запуску білду на трьох ОС: 
	■ runs-on: ubuntu-latest (Linux) 
	■ runs-on: windows-latest (Windows) 
	■ runs-on: macos-latest (macOS) 
○ Steps: Кожен білд повинен включати кроки: 
	■ Checkout коду (actions/checkout@v4). 
	■ Встановлення CMake (якщо потрібно). 
	■ Запуск команд конфігурації та білдування (запуск скрипту ci.bat). 
	■ Deploy.

Ось повністю готовий файл .github/workflows/ci.yml, який відповідає всім твоїм вимогам
name: Cross-platform Build and Test

on:
  push:
    branches:
      - "*develop*"
      - "*master*"
  pull_request:
    branches:
      - "*develop*"
      - "*master*"

jobs:
  cross_build:
    name: Build and Test on ${{ matrix.os }}
    runs-on: ${{ matrix.os }}

    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]

    steps:
      # 1️ Checkout репозиторію
      - name: Checkout repository
        uses: actions/checkout@v4

      # 2️ Встановлення CMake (на випадок, якщо не встановлено)
      - name: Set up CMake
        uses: jwlawson/actions-setup-cmake@v2
        with:
          cmake-version: 'latest'

      # 3️ Запуск команд конфігурації та білдування (через скрипт ci.bat)
      # Для Linux і macOS використовується bash, для Windows — cmd
      - name: Run CI script
        run: |
          if [ "${{ runner.os }}" = "Windows" ]; then
            call ci.bat
          else
            chmod +x ./ci.bat
            ./ci.bat
          fi
        shell: bash

      # 4️ Deploy (заглушка, можна замінити реальними командами)
      - name: Deploy
        run: echo "🚀 Deploy step (add real deployment commands here)"

The action is trying to download an old or incompatible version

Sometimes jwlawson/actions-setup-cmake@v2 fails to fetch a valid release, and the runner cancels it silently.

Fix:
Specify a known working version instead of “latest”:

- name: Set up CMake
  uses: jwlawson/actions-setup-cmake@v2
  with:
    cmake-version: '3.28.1'
